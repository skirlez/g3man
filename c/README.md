# c

This is some C code g3man uses. The CMake project here produces libg3man for use by g3man and libxdelta3.

libg3man is a small library that interfaces with libxdelta to provide a simpler API for g3man to use.

The libxdelta here is based off of https://github.com/marco-calautti/xdelta, modified to build a .so/dll shared library.
